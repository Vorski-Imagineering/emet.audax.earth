How Our Agent Uses Google Data

EMET works with an AI agent of its own. This page says what that agent does with the Google account it is given, and what it does not do.

Last updated 19 November 2026

Whose data

The agent signs in to one Google account, the team’s own emet.living.lab@gmail.com. It is not offered to the public, and no one else can sign it in to their account.

What it does with that account

On a team member’s request, the agent reads and sends mail, creates and updates calendar events and invitations, and creates and edits documents, spreadsheets and files in Drive. It uses read-only access to the account’s contacts to address mail and invitations.

What it does not do

  • It does not sell, rent or share Google data with anyone outside the EMET team.
  • It does not use Google data for advertising.
  • EMET does not use Google data to train AI models. The agent’s language model reads the content of a request only to carry that request out.

EMET’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where it is kept

The agent’s sign-in is stored on EMET’s own server and is not shared with any other service. Mail, calendar and files stay in Google; the agent keeps only what a task needs, such as notes of a meeting it was asked to arrange.

Removing access

The account’s owner can withdraw the agent’s access at any time at myaccount.google.com/permissions. Questions go to emet.living.lab@gmail.com.
